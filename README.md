# Edu-APK-Creator Tool

## Description
A simple Python GUI tool that generates an educational Android APK script. 
The generated APK demonstrates background camera usage, screen-off functionality, and auto-deletion features.

## Features
- **GUI Interface**: User-friendly interface to input APK name.
- **Auto Generation**: Automatically creates a target Python script for APK conversion.
- **Educational Logic**: 
  - Argument menu ("Do you want to try this?").
  - Simulated "Letter" option selection.
  - Turns screen OFF upon activation.
  - Activates Back Camera & takes screenshots in background.
  - Auto-deletes the APK/script after 2 minutes if no interaction occurs.

## Requirements
- Python 3.x
- Android Device (for testing the generated APK)
